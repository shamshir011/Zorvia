# Coffee App (Jetpack Compose UI)

A modern Coffee App UI built using Jetpack Compose.
This project focuses on clean and responsive UI design.

It showcases a smooth and intuitive user experience for browsing different coffee items, viewing details, and exploring a visually rich interface.
The app emphasizes modern Android development practices using declarative UI with Jetpack Compose.

---

## Features

* Home screen with coffee list
* Search UI
* Product detail screen
* Wishlist UI
* Modern Material Design
* Smooth scrolling (LazyColumn, LazyRow)

---

## Tech Stack

* Kotlin
* Jetpack Compose
* Material 3


---

## Purpose

* Learn Jetpack Compose
* Practice UI design
